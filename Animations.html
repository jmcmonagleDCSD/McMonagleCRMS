Step 1

A static box position in the flow of the webpage

Step 2

A relative box position in relation to where it started

Step 3

A absolute box position where it would like to be in the parent element

Step 4

A animation that moves your flower on your page giving it some life.

Step 1:

First make 2 boxes one being the container for your whole flower this will contain your entire flower the other is the center of the flower. Have both of them centered vertically and horizontally.

Step 2:

Next make a stem for your flower. This will be a long rectangle that is green. Position it so that it is at the bottom of the center box and centered using a relative position so you can over lap it with your center box.

Step 3:

Next make 4 pedals for your flower. These will be circles that are positioned around the center box using absolute positioning. You will need to make sure that the parent container is set to relative positioning so that the pedals are positioned in relation to the parent container.

Step 4:

Finally add an animation to the entire flower. You can use any animation you would like. You can use the example animation in the code if you would like.
